# 初见 Onboard
一个叫“初见 Onboard”的企业员工服务 AI 助手，包含四个入口：
- 员工页：像客服一样聊天，问公司制度、查自己的年假，回答带制度原文依据；解决不了可以转人工；还有制度中心、组织架构、工单与入职任务、消息待办、制度签收。
- HR 管理后台：管理员工、制度、年假、员工问询、工单、入职任务、制度更新与签收、制度冲突检查。
- 产品运营后台：看运营数据、知识缺口、回答质量的调试与评测、提示词的版本发布、模型连接。
- 学习后台：把这个产品当成教材，含设计理念、业务流程、架构图、专业 PRD、实训、面试作品，以及一个“导航 · 学习模式”，可以边点真实产品边看内部逻辑讲解。
